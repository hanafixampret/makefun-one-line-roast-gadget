One original line, under 200 characters, roasting a gadget used every day. `main.ts` writes it to `<output>/entry.txt` so the AI judge can compare it head to head against the other entries.

The roast: "My robot vacuum mapped my entire house, memorized every chair leg, and still eats the same charging cable every day like it's a new delicacy."

## Run it

```sh
node main.ts
```

This writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (or `/output` when that variable is unset).
